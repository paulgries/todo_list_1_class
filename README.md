Recall that a user story has the form "As a user, I want to TASK so that GOAL".

Read TodoListPanel.java. Which use cases does this implement?

As a user …

Answer: 
* I want to view my todo list so that I can choose what to do next
* I want to add a todo item so that I can keep track of tasks
* I want to remove a todo item so that I can manage my tasks
* I want to mark a todo item as done so that I can track my progress
* I want to unmark a todo item as done so that I can revisit tasks
* I want to save my todo list so that I can keep my changes
* When I open the app, I want to see my todo list so that I can start working on my tasks

Distractors:
* I want to filter my todo list by done or not done items so that I can focus on what needs to be done
* I want to set due dates for my todo items so that I can manage my time effectively
* I want to sort my todo list by priority or due date so that I can prioritize my tasks
* I want to edit a todo item so that I can update task details
* I want to categorize my todo items so that I can organize my tasks better
* I want to search for a todo item so that I can quickly find specific tasks
* I want to set reminders for my todo items so that I can be notified about upcoming tasks
